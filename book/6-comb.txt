== *6.0. Суммы от 1 до n*
$ S_c (n) = 1^c + 2^c + 3^c + ... + n^c $

Общая формула, $B_j$ - числа Бернулли: $B_0 = 1$,  $B_1 = 1 / 2$,  $B_2 = 1 / 6$,  $B_4 = -1 / 30$,  $B_6 = 1 / 42$,  $B_3 = B_5 = 0$
$ S_c (n) = 1 / (c + 1) sum_(j = 0)^c binom(c + 1, j) B_j n^(c + 1 - j) $
Большое $c$ по простому модулю: $S_c$ - многочлен степени $c + 1$, считаем его в точках $0..c + 1$ и интерполируем.

$ "sum"_k (n) = binom(n + k, k + 1) = (n(n + 1)...(n + k)) / (k + 1)! $

$ (a + b)^n = sum_(i = 0)^n binom(n, i) a^i b^(n - i), (1 + x)^n = sum_(i = 0)^n binom(n, i) x^i, 3^n = sum_(i = 0)^n binom(n, i) 2^i $
$ binom(n + 1, k + 1) = binom(n, k) + binom(n, k + 1) = binom(k, k) + binom(k + 1, k) + ... + binom(n, k) $
$ 1 + 3 + 5 + ... + (2n - 1) = n^2, 1 + x + x^2 + ... + x^n = (x^(n + 1) - 1)/(x - 1) $
$ x + 2x^2 + 3x^3 + ... + n x^n = (x(1 - (n + 1)x^n + n x^(n + 1)))/(1 - x)^2 $
== *6.1. Числа Фибоначчи и их свойства*
*Соотношение Кассини*, НОД-равенство
$ F_(n + 1) F_(n - 1) - F_n^2 = (-1)^n, gcd(F_m, F_n) = F_(gcd(m, n)) $
Правило "сложения", сумма квадратов
$ F_(n + k) = F_k F_(n + 1) + F_(k - 1)F_n, sum_(i = 1)^(n) F_i^2 = F_n F_(n + 1) $
*Теорема Цекендорфа* утверждает, что любое натуральное число n можно представить единственным образом в виде суммы чисел Фибоначчи 
$ N = F_k_1 + F_k_2 + F_k_3 + ... + F_k_r $
где $2 <= k_i$ и $k_i + 2 <= k_(i + 1)$ (т.е. в записи нельзя использовать два соседних числа Фибоначчи. $F_0 = 0, F_1 = 1, F_2 = 1, ...$)
Формула для n-го числа Фибоначчи
$ F_n = (Phi^n - Psi^n) / sqrt(5), Phi = (1 + sqrt(5)) / 2, Psi = (1 - sqrt(5)) / 2 $
$|Psi| < 1$, поэтому $F_n$ - это $Phi^n / sqrt(5)$, округлённое до ближайшего целого ($F_n approx 0.447 dot 1.618^n$). В ld точно до $n approx 80$, дальше только для оценки величины.
== *6.2. Код Грея*
$ G_i = i xor floor(i / 2) $
Соседние $G_(i - 1)$ и $G_i$ отличаются одним битом, его номер $"ctz"(i)$. Обратно $i$ по ``ulong g = G_i``: ``for (int k = 1; k < 64; k <<= 1) g ^= g >> k;``
== *6.3. Числа Каталана*
$ C_n = binom(2n, n) / (n + 1) = binom(2n, n) - binom(2n, n + 1), quad C_(n + 1) = sum_(i = 0)^n C_i C_(n - i) = C_n (4n + 2) / (n + 2) $
$1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796$, $C_n approx 4^n \/ (n^(3 \/ 2) sqrt(pi))$, в long до $C_35 approx 3.1 dot 10^18$.
$C_n$ - это кол-во:
ПСП из $n$ пар скобок; расстановок скобок в произведении $n + 1$ множителей;
двоичных деревьев из $n$ вершин (= полных двоичных с $n + 1$ листьями);
путей из $(0, 0)$ в $(n, n)$ шагами вправо и вверх, не поднимающихся выше диагонали $y = x$;
триангуляций выпуклого $(n + 2)$-угольника; способов соединить $2n$ точек на окружности $n$ непересекающимися хордами;
перестановок $n$ чисел, сортируемых одним стеком.
Отражение: путей из $(0, 0)$ в $(x, y)$ шагами $(1, plus.minus 1)$, не опускающихся ниже $O X$, где $b = (x - y) \/ 2$ шагов вниз:
$ binom(x, b) - binom(x, b - 1) $
Плохой путь касается $y = -1$. Отразив его начало до первого касания, получаем путь из $(0, -2)$, таких $binom(x, b - 1)$.
== *6.4. Пары с $a xor b = x$, $a + b <= s$*
$a + b = (a xor b) + 2 (a "&" b)$. Пусть $y = a "&" b$: тогда $y "&" x = 0$ и $y <= floor((s - x) \/ 2)$. Каждому $y$ соответствует $2^("popcount"(x))$ пар: каждый бит $x$ стоит либо в $a$, либо в $b$.
При $a + b = s$ ровно: $2^("popcount"(x))$ пар, если $s >= x$, $s - x$ чётно и $((s - x) \/ 2) "&" x = 0$, иначе $0$.

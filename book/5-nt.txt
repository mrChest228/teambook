$ & (x, y, g) = "gcdex"(n, m) \
& x n + y m = g, x n / g + y m / g = 1, x n / g eq.triple 1 thin (mod m / g) \
& n k + a eq.triple b thin (mod m) \
& n k eq.triple b - a thin (mod m) \
& n / g k eq.triple (b - a) / g thin (mod m / g) \
& k = (b - a) / g x \

=== *5.2.3. Обратное, степень и корень по модулю*
Обратное к $x$ по модулю $m$ есть, только если $gcd(x, m) = 1$. Корней степени $k$ из $c != 0$ по простому $p$ либо нет, либо ровно $d = gcd(k, p - 1)$. Корень есть, если $c^((p - 1) / d) eq.triple 1 thin (mod p)$. При $d = 1$ он равен $c^y$, где $k y eq.triple 1 thin (mod p - 1)$. Первообразный корень есть у любого простого.

=== *5.2.4. Свёртка Дирихле, Мёбиус*
$(f * g)(n) = sum_(d | n) f(d) g(n / d)$: коммутативна, ассоциативна, единица $epsilon(n) = [n = 1]$. Свёртка мультипликативных мультипликативна, считается решетом.
$mu * 1 = epsilon$, $phi * 1 = "id"$, $1 * 1 = tau$, $"id" * 1 = sigma$, $phi = mu * "id"$.
Обращение Мёбиуса: $g(n) = sum_(d | n) f(d)$ $<=>$ $f(n) = sum_(d | n) mu(d) g(n / d)$. Так $sum_(i, j <= n) [gcd(i, j) = 1] = sum_d mu(d) floor(n / d)^2$, $sum_(i, j <= n) gcd(i, j) = sum_d phi(d) floor(n / d)^2$.
$floor(n / d)$ принимает $<= 2 sqrt(n)$ значений: блок $d in [l, floor(n / floor(n / l))]$, нужны префиксные суммы $mu$ или $phi$. $gcd(x, y) <= |x - y|$ при $x != y$.

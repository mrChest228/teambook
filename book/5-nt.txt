=== *5.2.3. Обратное, степень и корень по модулю*
Обратное к $x$ по модулю $m$ есть, только если $gcd(x, m) = 1$. Корней степени $k$ из $c != 0$ по простому $p$ либо нет, либо ровно $d = gcd(k, p - 1)$. Корень есть, если $c^((p - 1) / d) eq.triple 1 thin (mod p)$. При $d = 1$ он равен $c^y$, где $k y eq.triple 1 thin (mod p - 1)$. Первообразный корень есть у любого простого.

=== *5.2.4. Мультипликативные функции, свёртка Дирихле*
$f$ мультипликативна, если $f(a b) = f(a) f(b)$ при $gcd(a, b) = 1$, вполне мультипликативна - при любых $a, b$. У любой мультипликативной $f(1) = 1$, и она задаётся значениями на степенях простых: $f(p_1^(a_1) dots p_k^(a_k)) = f(p_1^(a_1)) dots f(p_k^(a_k))$.
Основные, все мультипликативны:
$epsilon(n) = [n = 1]$, $1(n) = 1$, $"id"(n) = n$ - вполне мультипликативны;
$tau(n)$ - кол-во делителей, $tau(p^a) = a + 1$;
$sigma(n)$ - сумма делителей, $sigma(p^a) = (p^(a + 1) - 1) / (p - 1)$;
$phi(n)$ (Эйлер) - кол-во $1 <= k <= n$ с $gcd(k, n) = 1$: $phi(p^a) = p^a - p^(a - 1)$, $phi(n) = n product_(p | n) (1 - 1 / p)$;
$mu(n)$ (Мёбиус): $0$, если $n$ делится на квадрат простого, иначе $(-1)^k$, $k$ - кол-во простых в $n$. $mu(p) = -1$, $mu(p^a) = 0$ при $a >= 2$.
Все до $n$ - линейным решетом за $O(n)$: при $p < "lp"(i)$ $f(i p) = f(i) f(p)$, при $p = "lp"(i)$ $phi(i p) = phi(i) p$, $mu(i p) = 0$.
Свёртка Дирихле: $(f * g)(n) = sum_(d | n) f(d) g(n / d)$. $f * g = g * f$ (порядок не важен), $(f * g) * h = f * (g * h)$ (скобки не важны), $f * epsilon = f$. Свёртка мультипликативных мультипликативна.
$mu * 1 = epsilon$ (сумма $mu$ по делителям $n > 1$ равна $0$), $phi * 1 = "id"$, $1 * 1 = tau$, $"id" * 1 = sigma$, $phi = mu * "id"$.
Обращение Мёбиуса: $g(n) = sum_(d | n) f(d)$ $<=>$ $f(n) = sum_(d | n) mu(d) g(n / d)$.
Пример: $[gcd(i, j) = 1] = sum_(d | gcd(i, j)) mu(d)$. $d$ делит и $i$, и $j$ для $floor(n / d)^2$ пар, поэтому $sum_(i, j <= n) [gcd(i, j) = 1] = sum_d mu(d) floor(n / d)^2$. Так же из $gcd(i, j) = sum_(d | gcd(i, j)) phi(d)$: $sum_(i, j <= n) gcd(i, j) = sum_d phi(d) floor(n / d)^2$.
Блоки: в $sum_(d = 1)^n f(d) g(floor(n / d))$ значение $floor(n / d)$ принимает $<= 2 sqrt(n)$ разных значений ($d <= sqrt(n)$ - не больше $sqrt(n)$ штук $d$, при $d > sqrt(n)$ само $floor(n / d) < sqrt(n)$). Одинаковые идут подряд: для всех $d$ от $l$ до $r = floor(n / floor(n / l))$ оно одно и то же. $n = 10$: $10, 5, 3, 2, 2, 1, 1, 1, 1, 1$, блоки $[1, 1], [2, 2], [3, 3], [4, 5], [6, 10]$. Сумма за $O(sqrt(n))$ с префиксными суммами $F$ от $f$: ``for (int l = 1, r; l <= n; l = r + 1) { r = n / (n / l); ans += (F[r] - F[l - 1]) * g(n / l); }``
Решето Ду Цзяо (Du's sieve, по фамилии автора): префиксная сумма $S(n) = sum_(i <= n) f(i)$ за $O(n^(2 / 3))$, если найдётся $g$, у которой префиксные суммы $g$ и $h = f * g$ считаются за $O(1)$: $g(1) S(n) = sum_(i <= n) h(i) - sum_(d = 2)^n g(d) S(floor(n / d))$, справа блоки. Для $mu$: $g = 1$, $h = epsilon$, $M(n) = 1 - sum_(d = 2)^n M(floor(n / d))$. Для $phi$: $g = 1$, $h = "id"$, $Phi(n) = n (n + 1) / 2 - sum_(d = 2)^n Phi(floor(n / d))$. До $n^(2 / 3)$ - решетом, большие $S(floor(n / d))$ запоминаются. $M(10^(10))$ - 150 мс, $Phi$ без модуля - только до $5 dot 10^9$ (иначе переполнение). Как подобрать $g$: префиксные суммы $g$ и $h = f * g$ должны считаться формулой. $mu$: $g = 1$, $h = epsilon$; $phi$: $g = 1$, $h = "id"$; $n mu(n)$: $g = "id"$, $h = epsilon$; $n phi(n)$: $g = "id"$, $h = "id"^2$ (сумма $i^2$).

=== *5.2.5. Решето Min-25: сумма мультипликативной функции*
Задача: $S(n) = sum_(i <= n) f(i)$ для мультипликативной $f$, $n$ до $10^(11) - 10^(13)$. Условия: $f(p)$ на простых - многочлен от $p$ малой степени, $f(p^e)$ считается за $O(1)$.
Идея: любое $i >= 2$ однозначно записывается как $i = p^e m$, где $p$ - мин. простой делитель $i$, а все простые делители $m$ больше $p$. Тогда $f(i) = f(p^e) f(m)$. Простых до $n$ слишком много для перебора, поэтому их вклад считается отдельно (шаг 1), а составные собираются рекурсией по $p <= sqrt(n)$ (шаг 2).
Все суммы нужны только в точках $x = floor(n / d)$. Их не больше $2 sqrt(n)$, они лежат в ``w`` по убыванию, номер точки - ``id(x)``.
#br
Шаг 1, суммы по простым: $g_k (x) = sum_(p <= x) p^k$ для всех точек $x$.
Сначала в $g_k (x)$ кладётся сумма $i^k$ по всем $2 <= i <= x$ (``sumPow``).
Затем простые $p <= sqrt(n)$ идут по возрастанию, и из $g_k (x)$ вычёркиваются составные с мин. простым делителем $p$. Это числа $p m$, где $m <= floor(x / p)$ ещё не вычеркнуто и не простое меньше $p$. Сумма таких $m^k$ равна $g_k (floor(x / p)) - g_k (p - 1)$, поэтому при $x >= p^2$:
$g_k (x) arrow.l g_k (x) - p^k (g_k (floor(x / p)) - g_k (p - 1))$.
$g_k (p - 1)$ - сумма $q^k$ по простым $q < p$, в коде ``sp[k]``. Точки обходятся по убыванию $x$, чтобы справа стояли старые значения.
Пример: $n = 10$, $k = 0$. Точки $10, 5, 3, 2, 1$, сначала $g_0 = 9, 4, 2, 1, 0$. $p = 2$: $g_0 (10) = 9 - (g_0 (5) - 0) = 5$ (остались $2, 3, 5, 7, 9$), $g_0 (5) = 4 - (g_0 (2) - 0) = 3$. $p = 3$: $g_0 (10) = 5 - (g_0 (3) - g_0 (2)) = 4$ - простых до $10$ четыре.
Вклад простых в ответ: $sum_(p <= x) f(p) = sum_k c_k g_k (x)$, где $f(p) = c_0 + c_1 p + ... + c_(K - 1) p^(K - 1)$.
Если в задаче нужны только простые, хватает шага 1: $pi(x) = g_0 (x)$, сумма простых до $x$ равна $g_1 (x)$.
#br
Шаг 2, составные: ``calc(x, j)`` - сумма $f(i)$ по $2 <= i <= x$ с мин. простым делителем $>= p_j$ (простые с номера $0$).
Простые: $sum_k c_k (g_k (x) - g_k (p_j - 1))$.
Составные: перебирается мин. простой $p_i$ ($i >= j$, $p_i^2 <= x$) и его степень $e$. Числа $p_i^e m$ с $m >= 2$ дают $f(p_i^e) dot$ ``calc``$(floor(x / p_i^e), i + 1)$, а само число $p_i^(e + 1)$ даёт $f(p_i^(e + 1))$.
Ответ: ``calc(n, 0)`` $+ f(1)$, где $f(1) = 1$.
#br
Как подогнать код под задачу:
1) ``K`` и ``c`` - коэффициенты $f(p)$ по степеням $p$. $phi$: $p - 1$, $c = {-1, 1}$. $mu$: $-1$, $c = {-1}$. $tau$: $2$, $c = {2}$. $sigma$: $p + 1$, $c = {1, 1}$. $f(p^e) = a e + b p$: $a + b p$, $c = {a, b}$.
2) ``f(p, e, pe)`` - значение на $p^e$ по модулю. $phi$: $p^e - p^(e - 1)$. $mu$: $-[e = 1]$. $tau$: $e + 1$. $sigma$: $(p^(e + 1) - 1) / (p - 1)$.
3) При $K > 3$ дописать в ``sumPow`` сумму $i^k$ (3.0).
#br
Время $O(n^(3 / 4) / log(n))$: $n = 10^(10)$ - $0.3$ с, $10^(11)$ - $1.3$ с, $10^(12)$ - $6$ с, $10^(13)$ - $33$ с. За $O(n^(2 / 3))$ работает решето Ду Цзяо, но ему нужна удобная $g$, а здесь подходит любая $f$.
Сверено с Library Checker Sum of Multiplicative Function (Large). Только шаг 1: CF gym 103428 I ($n <= 10^(11)$, сумма простых на блоках $floor(n / p)$).

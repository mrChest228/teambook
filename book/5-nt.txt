=== *5.2.3. Обратное, степень и корень по модулю*
Обратное к $x$ по модулю $m$ есть, только если $gcd(x, m) = 1$. Корней степени $k$ из $c != 0$ по простому $p$ либо нет, либо ровно $d = gcd(k, p - 1)$. Корень есть, если $c^((p - 1) / d) eq.triple 1 thin (mod p)$. При $d = 1$ он равен $c^y$, где $k y eq.triple 1 thin (mod p - 1)$. Первообразный корень есть у любого простого.

== *5.3. Мультипликативные функции*
$f$ мультипликативна, если $f(a b) = f(a) f(b)$ при $gcd(a, b) = 1$, вполне мультипликативна - при любых $a, b$.
У любой мультипликативной $f(1) = 1$, и она задаётся значениями на степенях простых: $f(p_1^(a_1) dots p_k^(a_k)) = f(p_1^(a_1)) dots f(p_k^(a_k))$.
#br
Основные, все мультипликативны:
$epsilon(n) = [n = 1]$, $1(n) = 1$, $"id"(n) = n$ - вполне мультипликативны.
$tau(n)$ - кол-во делителей. $tau(p^a) = a + 1$.
$sigma(n)$ - сумма делителей. $sigma(p^a) = (p^(a + 1) - 1) / (p - 1)$.
$phi(n)$ (Эйлер) - кол-во $1 <= k <= n$ с $gcd(k, n) = 1$. $phi(p^a) = p^a - p^(a - 1)$, $phi(n) = n product_(p | n) (1 - 1 / p)$. Свойство: $sum_(d | n) phi(d) = n$.
$mu(n)$ (Мёбиус): $0$, если $n$ делится на квадрат простого, иначе $(-1)^k$, $k$ - кол-во простых в $n$. $mu(p) = -1$, $mu(p^a) = 0$ при $a >= 2$. Свойство: $sum_(d | n) mu(d) = [n = 1]$.
#br
Все значения до $n$ - линейным решетом за $O(n)$, $p = "lp"(i)$, $t = i / p$:
если $t$ не делится на $p$, то $f(i) = f(t) f(p)$;
если делится, то $phi(i) = phi(t) p$, $mu(i) = 0$.
Код - в ``init`` решета Ду Цзяо (5.3.4).
=== *5.3.1. Свёртка Дирихле*
$(f * g)(n) = sum_(d | n) f(d) g(n / d)$.
$f * g = g * f$ (порядок не важен), $(f * g) * h = f * (g * h)$ (скобки не важны), $f * epsilon = f$.
Свёртка мультипликативных мультипликативна.
Тождества:
$mu * 1 = epsilon$;
$phi * 1 = "id"$;
$1 * 1 = tau$;
$"id" * 1 = sigma$;
$phi = mu * "id"$.
Первые два - это свойства $mu$ и $phi$ из определений.
=== *5.3.2. Обращение Мёбиуса*
$g(n) = sum_(d | n) f(d)$ $<=>$ $f(n) = sum_(d | n) mu(d) g(n / d)$.
То есть $g = f * 1$ $<=>$ $f = g * mu$: свернули обе части с $mu$, а $1 * mu = epsilon$.
#br
Пример: $[gcd(i, j) = 1] = sum_(d | gcd(i, j)) mu(d)$.
$d$ делит и $i$, и $j$ для $floor(n / d)^2$ пар, поэтому $sum_(i, j <= n) [gcd(i, j) = 1] = sum_d mu(d) floor(n / d)^2$.
Так же из $gcd(i, j) = sum_(d | gcd(i, j)) phi(d)$: $sum_(i, j <= n) gcd(i, j) = sum_d phi(d) floor(n / d)^2$.
=== *5.3.3. Блоки $floor(n / d)$*
В $sum_(d = 1)^n f(d) g(floor(n / d))$ значение $floor(n / d)$ принимает $<= 2 sqrt(n)$ разных значений: $d <= sqrt(n)$ - не больше $sqrt(n)$ штук $d$, а при $d > sqrt(n)$ само $floor(n / d) < sqrt(n)$.
Одинаковые идут подряд: для всех $d$ от $l$ до $r = floor(n / floor(n / l))$ оно одно и то же.
$n = 10$: $10, 5, 3, 2, 2, 1, 1, 1, 1, 1$, блоки $[1, 1], [2, 2], [3, 3], [4, 5], [6, 10]$.

=== *5.3.4. Решето Ду Цзяо: суммы $mu$ и $phi$*
Du's sieve, по фамилии автора. Обозначения: $phi(n)$ - сама функция, $S_phi (n) = sum_(i <= n) phi(i)$ - её префиксная сумма, так же $S_mu$.
Считает $S_f (n)$ за $O(n^(2 / 3))$, если найдётся $g$, у которой префиксные суммы $g$ и $h = f * g$ считаются формулой:
$g(1) S_f (n) = sum_(i <= n) h(i) - sum_(d = 2)^n g(d) S_f (floor(n / d))$, справа блоки.
#br
Для $mu$: $g = 1$, $h = epsilon$, $S_mu (n) = 1 - sum_(d = 2)^n S_mu (floor(n / d))$.
Для $phi$: $g = 1$, $h = "id"$, $S_phi (n) = n (n + 1) / 2 - sum_(d = 2)^n S_phi (floor(n / d))$.
Для $n mu(n)$: $g = "id"$, $h = epsilon$.
Для $n phi(n)$: $g = "id"$, $h = "id"^2$ (сумма $i^2$).
#br
Какие точки нужны: только $x = floor(n / d)$ (вложенность блоков).
Малые $x < S approx n^(2 / 3)$ - префиксные суммы из решета, массивы ``sumMu``, ``sumPhi``.
Больших $x >= S$ всего $n / S approx n^(1 / 3)$ штук, нужно $n / S < B$: при $S = 5 dot 10^6$, $B = 10^5$ это $n <= 5 dot 10^(11)$. Их значения надо запомнить: формула обращается к одной точке из многих других, без запоминания она пересчитывалась бы каждый раз. Хватает массива с индексом $d$: ``bigMu[d]`` - сумма в точке $floor(n / d)$.
Точки идут по возрастанию $x$, тогда все нужные $floor(x / l) = floor(n / (d l))$ уже готовы, рекурсия не нужна.
#br
Всё по модулю. Точная сумма $phi$ влезает в ``long`` только до $n approx 5 dot 10^9$.
Время: $n = 10^(10)$ - $0.16$ с, $10^(11)$ - $1.9$ с при $S = 5 dot 10^6$.

=== *5.3.5. Решето Min-25: сумма мультипликативной функции*
Задача: $S(n) = sum_(i <= n) f(i)$ для мультипликативной $f$, $n <= 10^(12)$. Условия: $f(p)$ на простых - многочлен от $p$ малой степени, $f(p^e)$ считается за $O(1)$.
Идея: любое $i >= 2$ однозначно записывается как $i = p^e t$, где $p$ - мин. простой делитель $i$, а все простые делители $t$ больше $p$. Тогда $f(i) = f(p^e) f(t)$. Сначала считается сумма $f$ только по простым (шаг 1), затем к ней возвращаются составные (шаг 2).
#br
Точки: все суммы нужны только при $x = floor(n / d)$. Порог $y approx n^(2 / 3) / 10$.
Большие точки $x > y$: их $m = floor(n / (y + 1))$ штук, значение для $floor(n / d)$ лежит в массиве по индексу $d$.
Малые $x <= y$: до $y$ есть линейное решето (``lp``, ``fv[i]`` $= f(i)$), сумма по простым до $x$ - ``pr[x]``, а суммы с составными держит дерево Фенвика ``fw``.
#br
Шаг 1, ``primeSum``: $g_k (x) = sum_(p <= x) p^k$.
Сначала в $g_k (x)$ лежит сумма $i^k$ по всем $2 <= i <= x$ (``sumPow``).
Простые $p <= sqrt(n)$ идут по возрастанию, из суммы вычёркиваются числа $p t$ с мин. простым делителем $p$. Среди $t <= floor(x / p)$ подходят ещё не вычеркнутые, кроме простых меньше $p$, поэтому при $x >= p^2$:
$g_k (x) arrow.l g_k (x) - p^k (g_k (floor(x / p)) - g_k (p - 1))$.
Точки идут по убыванию $x$, чтобы справа стояли старые значения.
Пример: $n = 10$, $k = 0$. Точки $10, 5, 3, 2, 1$, сначала $g_0 = 9, 4, 2, 1, 0$. $p = 2$: $g_0 (10) = 9 - (g_0 (5) - 0) = 5$ (остались $2, 3, 5, 7, 9$), $g_0 (5) = 4 - (g_0 (2) - 0) = 3$. $p = 3$: $g_0 (10) = 5 - (g_0 (3) - g_0 (2)) = 4$ - простых до $10$ четыре.
Итог шага: ``res[d]`` $= sum_k c_k g_k (floor(n / d))$ - сумма $f(p)$ по простым $p <= floor(n / d)$, для малых $x$ - ``pr[x]``.
Если в задаче нужны только простые (их кол-во, сумма), хватает ``init`` и ``primeSum``: $c = {1}$ или $c = {0, 1}$.
#br
Шаг 2: простые идут по убыванию, в сумму возвращаются составные с мин. простым делителем $p$. Для $x >= p^2$ и каждой степени $e$:
числа $p^e t$, $t > 1$, дают $f(p^e) dot (R(floor(x / p^e)) - $``pr[p]``$)$, где $R$ - текущая сумма в точке (в ней простые и составные с мин. делителем больше $p$);
само число $p^(e + 1)$ даёт $f(p^(e + 1))$.
Ответ: ``res[1]`` $+ f(1)$.
#br
Почему быстро: большую точку меняют только простые $p <= sqrt(x)$. Справа стоит точка $z = floor(x / p)$. Если $z < p^2$, то составных в её сумме нет, и это готовое ``pr[z]`` за $O(1)$. Дерево Фенвика читается только при $x >= p^3$, поэтому и обновляется только для $p <= n^(1 / 3)$.
#br
Как подогнать код под задачу:
1) ``K`` и ``c`` - коэффициенты $f(p)$ по степеням $p$, в коде по модулю: $-1$ пишется как ``MOD - 1``.
$phi$: $p - 1$, $c = {-1, 1}$.
$mu$: $-1$, $c = {-1}$.
$tau$: $2$, $c = {2}$.
$sigma$: $p + 1$, $c = {1, 1}$.
$f(p^e) = a e + b p$: $a + b p$, $c = {a, b}$.
2) ``f(p, e, pe)`` - значение на $p^e$ по модулю.
$phi$: $p^e - p^(e - 1)$.
$mu$: $-[e = 1]$.
$tau$: $e + 1$.
$sigma$: $(p^(e + 1) - 1) / (p - 1)$.
3) При $K > 3$ дописать в ``sumPow`` сумму $i^k$ (6.0).
4) ``Y`` и ``B``: $y < Y$, $n / y < B$. При $n = 10^(12)$ это $10^7$ и $10^5$, память $16 Y$ байт.
#br
Время (сумма $phi$): $n = 10^(10)$ - $0.16$ с, $10^(11)$ - $0.5$ с, $10^(12)$ - $2.2$ с.
Сверено с Library Checker Sum of Multiplicative Function (Large). Только шаг 1: CF gym 103428 I ($n <= 10^(11)$, сумма простых на блоках $floor(n / p)$) - $0.35$ с.

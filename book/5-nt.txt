== *5.1. КТО*
$ cases("ans" eq.triple a thin (mod n), "ans" eq.triple b thin (mod m)) $
$ & (x, y, g) = "gcdex"(n, m) \
& x n + y m = g, x n / g + y m / g = 1, x n / g eq.triple 1 thin (mod m / g) \
& n k + a eq.triple b thin (mod m) \
& n k eq.triple b - a thin (mod m) \
& n / g k eq.triple (b - a) / g thin (mod m / g) \
& k = (b - a) / g x \
& "ans" = (b - a) / g x n + a $

=== *5.2.3. Обратное, степень и корень по модулю*
Обратное к $x$ по модулю $m$ есть, только если $gcd(x, m) = 1$. Тогда $x^(-1) eq.triple x^(phi(m) - 1) thin (mod m)$ (Эйлер), при простом $m$ это $x^(m - 2)$. Корней степени $k$ из $c != 0$ по простому $p$ либо нет, либо ровно $d = gcd(k, p - 1)$. Корень есть, если $c^((p - 1) / d) eq.triple 1 thin (mod p)$. При $d = 1$ он равен $c^y$, где $k y eq.triple 1 thin (mod p - 1)$. Первообразный корень есть у любого простого.

=== *5.2.4. Взаимная простота, $6 / pi^2$*
$ sum_(k >= 1) 1 / k^2 = pi^2 / 6, quad product_p (1 - 1 / p^2) = 6 / pi^2 approx 0.608 $
Два случайных числа не делятся оба на простое $p$ с вероятностью $1 - 1 / p^2$, поэтому взаимно просты с вероятностью $6 / pi^2$. $k$ чисел - $1 / zeta(k)$: для 3 чисел $approx 0.832$.
Пар $1 <= a, b <= n$ с $gcd(a, b) = 1$: $approx 0.608 n^2$ ($n = 10^5$: $6079301507$, оценка $6079271019$), точно $sum_d mu(d) floor(n / d)^2$. С $gcd = g$ - столько же для $floor(n / g)$.
$sum_(i = 1)^n phi(i) approx 3 n^2 / pi^2 approx 0.304 n^2$. Свободных от квадратов до $n$: $approx 0.608 n$, точно $sum_(d <= sqrt(n)) mu(d) floor(n / d^2)$.
Где пригодится: оценка ответа и размера перебора; отбор только взаимно простых пар оставляет $61%$ пар, асимптотику не меняет; случайная взаимно простая пара находится в среднем за $pi^2 / 6 approx 1.64$ попытки; точек решётки $n times n$, видимых из $(0, 0)$, $approx 0.608 n^2$.

== *5.4. Floor sum*
